Learn to code with games · Lesson 1

Star Catcher

Play the game, then change its code. Every game is a loop that does two things about 60 times a second: update the numbers, then draw the picture. Edit anything on the right and press Run to see what happens. You can't break anything; Reset brings the original back.

Click the game, then use ← →. On a phone, drag your finger across it.

The codeJavaScript

The five parts of every game

The code is split into five numbered parts. Almost every game you'll ever make, from Pong to Minecraft, has these same pieces.

  1. PART 1Setup

    Grab the canvas, the blank rectangle we paint on. ctx is our paintbrush.

  2. PART 2Variables

    The game's memory. let score = 0 makes a box named score holding 0. let can change later; const can't.

  3. PART 3Input

    Event listeners wait for the player. When a key goes down, we write it into keys.

  4. PART 4Functions

    Named recipes. update() changes the numbers; draw() paints them. if lets the game make decisions.

  5. PART 5Game loop

    loop() calls update, then draw, then asks the browser to run it again next frame. Forever.

Quests

Do these in order. Each one teaches a new idea. Try it yourself before opening the hint.

LVL 1

Paint job

Change the basket's color and the sky's color. Colors like "#ff7ab6" are hex codes, and plain words like "lime" work too.

Hint

Look inside draw() for ctx.fillStyle. The line right before the basket is drawn sets its color.

LVL 2

Easy mode

Make the basket wider and faster, and give the player 5 lives. You only need to change numbers.

Hint

All of these live in Part 2. Lives appear in two places: the start, and inside restart().

LVL 3

It gets harder

Make stars fall faster as your score goes up. This is how real games add difficulty.

Hint

In makeStar(), the fall speed is 2 + Math.random() * 2. Add something that grows with score:

fall: 2 + Math.random() * 2 + score * 0.1
LVL 4

Watch out for rocks

Some falling things should be grey rocks. Catching a rock costs a life instead of scoring a point.

Hint 1

Give each star a true/false value when it's made: rock: Math.random() < 0.2 means "20% chance of being a rock".

Hint 2

When drawing, pick the color with an if. When catching, check it too:

if (star.rock) {
  lives = lives - 1;
} else {
  score = score + 1;
}

One more thing: a rock that falls off the bottom shouldn't cost a life.
